Install

Install Nati

The button opens GNOME Software or KDE Discover. After installing, Nati updates together with your system and you can find it in the app store. Requires Flatpak (preinstalled on Fedora, Linux Mint and many others).

Terminal:

flatpak install --user https://kamdevapp.github.io/flatpak/nati.flatpakref

Zainstaluj Nati

Przycisk otwiera GNOME Software albo KDE Discover. Po instalacji Nati aktualizuje się razem z systemem i jest w wyszukiwarce sklepu. Potrzebny Flatpak (jest od razu w Fedorze, Linux Mincie i wielu innych).

Repository only · Samo repozytorium

flatpak remote-add --user --if-not-exists nati https://kamdevapp.github.io/flatpak/nati.flatpakrepo
